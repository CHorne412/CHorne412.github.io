# CHorne412.github.io

Personal portfolio and blog — built with Jekyll, hosted natively on GitHub Pages.

🔗 Live at: https://CHorne412.github.io

## Structure
- `_config.yml` — site config
- `_layouts/` — custom page/post layouts
- `_posts/` — blog posts (markdown)
- `assets/css/` — single stylesheet
- `index.md` — homepage / portfolio
